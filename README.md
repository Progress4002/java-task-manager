# java-task-manager
A console based task management application developed in Java using object-oriented programming

#Features
Create Task 
List Task 
Set task priorities
Mark task as completed
Delete task
Basic input Validation

#Technologies 
Java
Object Oriented Programming

src/

│ └── Main.java 
├── Logic/ 
│ └── Task.java 
└── enums/ 
    ├── Priority.java 
    └── Status.java
